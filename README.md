# COMANDOS BÁSICOS DE GIT ↙️

## git version: 
Muestra la versión de git que tengo instalada en mi pc
Ejemplo de uso: git --version

## git init
Creo un repositorio en mi carpeta seleccionada (git empieza a trabajar aquí)
Ejemplo de uso: git init

## git add
Es para seleccionar los archivos que voy a guardar
Ejemplo de uso: git add .

## git commit
Es como un punto de autoguardado, que lleva un comentario descriptivo de lo que se quiere guardar
Ejemplo de uso: git commit -m "Primer commit"

## git status 
Veo qué archivos estan pendientes de guardar
Ejmplo de uso: git status
